# V8.3 → V8.4 Handoff

V8.3 implements the Cognitive instrument as an objective single-choice assessment.

## Accepted

- 24 items
- 4 dimensions × 6 items
- 4 options per item
- one hidden correct option per item
- objective correct/incorrect scoring
- Cognitive V2 configuration/scoring/interpretation/selection/taxonomy version boundary
- customer runtime renders item-specific choices
- correct answer is not exposed in the customer question payload
- additive QuestionVersion metadata migration
- no IQ claim or norming introduced

## Not accepted / intentionally deferred

- IQ norming
- population percentile tables
- psychometric validation claims
- adaptive testing
- item calibration from production telemetry
- content authoring UI for objective options
- changes to EQ/DISC/RIASEC

## Deployment sequence

1. Run typecheck/build and V8.0–V8.3 gates.
2. Apply the additive Prisma migration.
3. Run the Cognitive V2 seed once.
4. Verify 24 published Cognitive V2 QuestionVersions exist.
5. Run a real HTTP Cognitive attempt and verify:
   - 24 questions
   - 4 options per question
   - answers restricted to 1–4
   - persistence/reload
   - submit
   - objective scoring
   - `COGNITIVE_SCORE_V2`
   - `COGNITIVE_RESULT_V2`
   - no correct answer exposed in customer payload.
6. Only after acceptance proceed to V8.4 EQ Instrument.

The V8.3 score is a product Cognitive Reasoning Score. It is not an IQ score.
