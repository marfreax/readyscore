# V8.1 → V8.2 Handoff

V8.1 is the locked measurement contract.

V8.2 may implement the required question/scoring architecture, but must not:
- change the locked construct;
- change the locked response model;
- introduce a universal score;
- silently change customer terminology;
- overwrite historical question versions.

The implementation sequence is:

```text
V8.1 LOCK
  ↓
V8.2 Question & Scoring Architecture
  ↓
V8.3 Cognitive
V8.4 EQ
V8.5 DISC
V8.6 RIASEC
```

Any necessary change to the V8.1 contract must be recorded explicitly before implementation proceeds.
