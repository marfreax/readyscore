# ReadyScore V15.2 — Customer Report Experience & Full E2E

## Contract

V15.2 turns the frozen V15.1 interpretation/report engine into a normal customer-facing product path.

Customer path:

BUY → GET ACCESS → COMPLETE 4 ASSESSMENTS → V13 RESULTS → PERSONALIZED REPORT → 5–7 MAJORS → REASONS → 30-DAY ACTION PLAN → 20+ PAGE REPORT

## Boundaries

- V13 scoring/result contracts remain read-only inputs.
- V14 entitlement/payment semantics remain the access authority.
- V15.1 remains the deterministic interpretation/matching/action-plan/report engine.
- Customer report generation is idempotent through the existing source fingerprint.
- A report is not considered customer-ready until all four core assessment types have completed results.
- PDF export is presentation-only and does not mutate results or report data.

## Runtime surfaces

- `/reports` — report workspace and V15 readiness CTA.
- `/reports/personalized` — full 20+ page personalized report experience.
- `/api/reports/personalized` — authenticated customer report/readiness API.

## Validation

- `pnpm v15.2:gate` — static customer report experience contract.
- `pnpm e2e:v15.2:customer` — real HTTP + PostgreSQL validation. Requires `READYSCORE_SESSION_COOKIE` for an authenticated customer session.
