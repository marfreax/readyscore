# ReadyScore V14.4 FIX4 — Customer Assessment Metadata Alignment

## Purpose

Align customer-facing assessment metadata with the already-frozen V13 production assessment configuration. This fix does not change V13 measurement, scoring, question selection, package configuration, timer runtime, or assessment lifecycle.

## Problem Observed

The V14.4 FIX3 customer journey correctly reached `PAID` and unlocked assessment access, but the shared customer assessment catalog still exposed legacy 24-question metadata for Cognitive, EQ, and DISC, with legacy shorter duration labels. The public landing shell also contained legacy EQ/DISC question-count copy.

## Correct Production Customer Metadata

| Assessment | Questions | Duration |
|---|---:|---:|
| Cognitive | 40 | 20 menit |
| EQ | 50 | 20 menit |
| DISC | 80 | 20 menit |
| RIASEC | 60 | 20 menit |

## Changes

1. `lib/assessment/catalog.ts` now derives production question counts from `ASSESSMENT_CONFIG` for all four paid assessments.
2. Customer catalog duration is aligned to the production 20-minute timer.
3. `components/assessment/AssessmentRunner.tsx` no longer describes Cognitive as a 24-question assessment.
4. `app/page.tsx` no longer advertises legacy 24-question EQ/DISC copy.
5. V14.4 static gate now explicitly protects the customer-facing metadata boundary and the V13 production counts/timer.

## Non-Changes

- No Prisma migration.
- No scoring changes.
- No measurement changes.
- No question-bank changes.
- No package-selection changes.
- No timer-runtime changes.
- No payment/fulfillment/entitlement changes.
