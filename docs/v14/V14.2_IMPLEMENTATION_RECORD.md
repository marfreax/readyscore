# ReadyScore V14.2 — Payment Gateway Integration

Status: ACTIVE / DEVELOPMENT

## Scope

V14.2 implements the payment-provider boundary defined by the V14 specification:

- provider adapter
- payment creation
- server-side payment status verification
- webhook endpoint
- webhook signature verification
- provider-reference reconciliation
- idempotent webhook processing
- valid payment state transitions
- payment audit events
- failure/retry foundation

## Provider

Initial provider: **Midtrans Snap**.

The domain boundary remains provider-agnostic through `PaymentProvider`. Provider-specific behavior is isolated in `lib/commercial/midtrans.ts` and `lib/commercial/midtrans-security.ts`.

## Runtime Contracts

- `POST /api/commercial/payments`
- `POST /api/commercial/payments/verify`
- `POST /api/commercial/webhooks/midtrans`

## Environment

See `.env.v14.2.example`.

Required for real sandbox provider validation:

```text
READYSCORE_PAYMENT_PROVIDER=MIDTRANS
MIDTRANS_ENVIRONMENT=sandbox
MIDTRANS_SERVER_KEY=<Midtrans sandbox server key>
```

## Validation

Static:

```text
pnpm v14.2:gate
```

Functional:

```text
pnpm e2e:v14.2:payment
```

The functional E2E requires Midtrans sandbox credentials for provider creation and verification. It must not be called PASS until the real sandbox environment has been exercised.
