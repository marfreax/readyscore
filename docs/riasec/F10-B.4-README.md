## Why approval is not automated

The 84 items were generated as candidate content.

A deterministic script cannot legitimately certify:

- construct validity
- wording quality
- cultural appropriateness
- construct contamination
- item discrimination
- psychometric quality

Therefore:

```text
MAPPED
   ↓
PENDING_REVIEW
   ↓
human review
   ↓
APPROVED
```

is intentional.

## Review procedure

```text

```

```text

```

to:

```text

```
