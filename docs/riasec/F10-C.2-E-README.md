# F.10-C.2-E — Actual RIASEC Runtime E2E

This test uses the actual HTTP routes and PostgreSQL runtime.

Run the application first:

```bash
pnpm dev
```

Then:

```bash
pnpm e2e:riasec
```

The test:

1. Starts `riasec`.
2. Requires exactly 60 runtime questions.
3. Requires 10 questions per R/I/A/S/E/C.
4. Persists answer `3` for every selected question.
5. Reloads the attempt through the real GET route.
6. Requires 60 answered questions.
7. Submits through the real submit route.
8. Requires a result payload.

It does not mutate the Question Bank lifecycle. It creates only an assessment attempt, answers, and result.


## Final production gate

Run `pnpm riasec:gate` before `pnpm riasec:publish`. The gate is non-mutating and requires the explicit human-review artifact plus an APPROVED_FOR_PUBLICATION manifest.

Then run `pnpm riasec:publish` followed by `pnpm e2e:riasec`.
