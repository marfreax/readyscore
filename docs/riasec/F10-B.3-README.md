## Canonical mapping folder

From this phase onward, any **standalone mapping artifact** belongs here:

```text
data/question-bank/mappings/
```

For RIASEC:

```text
data/question-bank/mappings/
└── RIASEC_QB_V1_MAPPING.csv
```

The source candidate bank remains here:

```text
data/question-bank/source/
└── RIASEC_QB_V1_FULL_84_CANDIDATE.csv
```

Do not put mapping files under:

```text
lib/assessment/riasec/
```

`lib/assessment/riasec/` is runtime/application code.

## Important distinction

The imported CSV already contains:

```text
domain
subdomain
indicator
mappingStatus
```

Therefore F.10-B.3 does NOT create a second mapping truth.

The standalone mapping file is an **audit/review artifact** and must remain synchronized with the Question Bank import.
