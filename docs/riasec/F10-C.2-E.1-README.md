# F.10-C.2-E.1 — Runtime Start Transaction Diagnostics & Reconciliation

This phase isolates the real `POST /api/assessment/start` failure using the same Prisma transaction shape as `createAttempt`.

## Safety

The diagnostic creates the real `AssessmentAttempt` + 60 `AttemptQuestion` records **inside a transaction and deliberately rolls the transaction back**. Therefore it performs no persistent database mutation.

## Run

```bash
rm -rf .next
pnpm typecheck
pnpm build
pnpm riasec:start:diagnostic
```

Optional HTTP diagnostic:

```bash
pnpm dev
curl -sS -X POST http://localhost:3000/api/assessment/start/diagnostic   -H 'content-type: application/json'   -d '{"seed":"F10-C2-E1"}'
```

The diagnostic reports the underlying Prisma error, including `code` and `meta`, if the real start transaction shape fails.

Only after this gate passes should `pnpm e2e:riasec` be rerun.
