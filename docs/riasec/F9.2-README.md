# PHASE 3.0-D.1-F.9.2 — Runtime Service Dispatch Wiring

F9.1 already provides the scoring dispatch boundary. F9.2 connects the
actual `lib/assessment/runtime-service.ts` submit flow to that boundary.

## Change

Replace:

```ts
import { calculateResult } from "./scoring-engine";
```

with:

```ts
import { calculateRuntimeAssessmentResult } from "./riasec/runtime-dispatch";
```

And replace the submit-time `calculateResult(...)` call with
`calculateRuntimeAssessmentResult(...)`.

The existing submit metadata must be passed unchanged, with
`assessmentConfigurationVersion` included.

## Result

```text
FREE / PREMIUM
    -> existing generic scorer

RIASEC
    -> calculateRuntimeAssessmentResult()
    -> scoreRiasec()
    -> RIASEC_RESULT_V1 adapter
```

## Important

Do not replace the entire runtime-service.ts. Do not modify scoring-engine.ts,
Prisma, or persistence in F9.2.

rm -rf .next
