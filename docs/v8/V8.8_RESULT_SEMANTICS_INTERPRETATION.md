# ReadyScore V8.8 — Result Semantics & Interpretation

**Status:** IMPLEMENTED / CONTRACT LOCK  
**Scope:** Result meaning, interpretation hierarchy, terminology, claim governance, and assessment-specific result boundaries.  
**Protection:** No measurement mutation, no scoring mutation, no question-bank mutation, no database migration.

## 1. Purpose

V8.8 formalizes the chain after scoring:

```text
USER RESPONSE
    ↓
MEASUREMENT / SCORING
    ↓
RESULT CONTRACT
    ↓
RESULT SEMANTICS
    ↓
INTERPRETATION
    ↓
CUSTOMER UNDERSTANDING
```

The result layer must explain what an assessment result means without changing how the result was measured.

The four assessments remain semantically distinct. V8.8 does **not** introduce a universal score and does not average unrelated assessment scores.

## 2. Non-negotiable boundaries

1. Result interpretation must use the assessment-specific result contract and scoring version.
2. Interpretation must not rescore an attempt.
3. Interpretation must not infer unsupported psychometric properties.
4. Internal scoring keys, mappings, and implementation metadata must not be exposed to customers.
5. Historical result semantics remain immutable through explicit version identities.
6. `overallScore` in the generic compatibility envelope is not automatically a customer-facing overall score.
7. Cross-test profile remains a synthesis layer; it is not replaced by V8.8.

## 3. Result hierarchy

```text
RESULT
├── Main Result
├── Dimension / Profile
├── Interpretation
└── Detailed Explanation
```

Each branch has assessment-specific semantics.

### Cognitive

- Main result: **Cognitive Score**
- Dimensions: Verbal, Numerical, Logical, Abstract Reasoning
- Meaning: normalized objective performance across the V2 item set.
- Customer interpretation: relative performance patterns across reasoning dimensions.
- Prohibited: calling the result **IQ**, clinical diagnosis, or a deterministic academic/career decision.

### EQ

- Main result: **EQ Score**
- Dimensions: Emotion Awareness, Emotion Regulation, Empathy / Social Awareness, Relationship / Social Response
- Meaning: 0–100 summary of keyed ordinal responses to the V2 situational items.
- Customer interpretation: relative response patterns to presented situations.
- Prohibited: clinical diagnosis, standardized population norm claim, deterministic academic/career decisions.

### DISC

- Main result: **Primary Behavioral Pattern**
- Secondary result: **Secondary Behavioral Pattern**
- Profile: D / I / S / C ipsative shares.
- Meaning: relative share of forced choices mapped to behavioral dimensions.
- Customer interpretation: behavioral response tendencies, potential strengths, and potential challenges.
- The generic `overallScore` is a compatibility envelope only and must not be presented as a substantive ability score.
- Prohibited: aptitude/intelligence claims, clinical diagnosis, deterministic career decisions, universal score.

### RIASEC

- Main result: **RIASEC Interest Profile**
- Profile: six interest dimensions.
- Highlight: **Top Interest Code** / `topCode`.
- Meaning: relative vocational-interest preference pattern.
- Customer interpretation: interest exploration and relative interest profile.
- Prohibited: ability/intelligence claims and guaranteed career/major fit.

## 4. Interpretation status and confidence

The existing result interpretation statuses remain:

```text
COMPLETE
PARTIAL
INSUFFICIENT
```

Confidence remains:

```text
HIGH
MODERATE
LIMITED
```

These classifications describe the available evidence for interpretation. They are not psychometric validity coefficients, percentiles, or population norms.

## 5. Claim governance

Every interpreted result exposes three claim classes:

- **allowed:** claims directly supported by the instrument semantics;
- **restricted:** claims requiring additional qualification or downstream evidence;
- **prohibited:** claims outside the measurement boundary.

The claim policy is assessment-specific.

## 6. Version alignment

| Assessment | Result Contract | Scoring | Interpretation |
|---|---|---|---|
| Cognitive | `COGNITIVE_RESULT_V2` | `COGNITIVE_SCORE_V2` | `COGNITIVE_INTERPRETATION_V2` |
| EQ | `EQ_RESULT_V2` | `EQ_SCORE_V2` | `EQ_INTERPRETATION_V2` |
| DISC | `DISC_RESULT_V2` | `DISC_SCORE_V2` | `DISC_INTERPRETATION_V2` |
| RIASEC | `RIASEC_RESULT_V2` | `RIASEC_SCORE_V2` | `RIASEC_INTERPRETATION_V2` |

A mismatch is a configuration error, not a reason to silently fall back to an older interpretation.

## 7. Customer-facing language

Customer language must describe the evidence actually produced.

Do not transform:

```text
relative profile
```

into:

```text
absolute ability
```

Do not transform:

```text
interest pattern
```

into:

```text
guaranteed career fit
```

Do not transform:

```text
behavioral tendency
```

into:

```text
fixed personality identity
```

Do not transform:

```text
Cognitive Score
```

into:

```text
IQ
```

without a separate approved psychometric basis.

## 8. Cross-test boundary

V8.8 does not create a universal result.

```text
COGNITIVE → cognitive result
EQ       → EQ result
DISC     → behavioral profile
RIASEC   → interest profile
```

Cross-test synthesis remains separate and must not average incompatible scores.

## 9. Implementation

V8.8 adds a result-semantics registry and validator:

```text
lib/assessment/result/semantics-v1.ts
```

The validator is intentionally post-scoring. It validates semantic/version alignment and does not modify scores.

No Prisma schema change or database migration is required.

## 10. Regression requirements

For each assessment:

```text
result contract
    ↓
scoring version
    ↓
interpretation version
    ↓
main result meaning
    ↓
dimension/profile meaning
    ↓
claim governance
```

The implementation must preserve the V8.3–V8.7 instrument contracts.

## 11. V8.8 acceptance criteria

- Four assessment-specific semantic definitions exist.
- Result, scoring, and interpretation versions are explicitly aligned.
- Interpretation cannot silently reinterpret a different scoring version.
- Cognitive remains non-IQ.
- EQ remains non-clinical and non-normative.
- DISC remains ipsative and without a substantive overall ability score.
- RIASEC remains an interest profile with descriptive topCode.
- Universal score remains prohibited.
- No raw-average synthesis is introduced.
- No database migration is introduced.
- Existing interpretation engines remain the source of assessment-specific narrative content.
