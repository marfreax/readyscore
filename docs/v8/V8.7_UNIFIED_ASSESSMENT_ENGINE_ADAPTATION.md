# ReadyScore V8.7 — Unified Assessment Engine Adaptation

**Status:** LOCKED / IMPLEMENTATION PHASE
**Scope:** orchestration only
**Database migration:** none

## 1. Objective

V8.7 introduces a single runtime orchestration boundary for the six existing assessment types without collapsing their measurement semantics into one scoring model.

The unified layer is responsible for:

- assessment dispatch;
- response-model declaration;
- question-count boundary validation;
- scoring-version provenance validation;
- delegation to the assessment-specific scoring engine.

It is **not** responsible for inventing or normalizing measurement semantics.

## 2. Assessment-specific contracts

| Assessment | Response model | Questions | Scoring remains |
|---|---|---:|---|
| Cognitive | SINGLE_CHOICE_4 | 24 | Objective Cognitive V2 engine |
| EQ | SINGLE_CHOICE_4 | 24 | EQ V2 engine |
| DISC | FORCED_CHOICE_4 | 24 | DISC V2 engine |
| RIASEC | LIKERT_5 | 60 | RIASEC V2 engine |
| free | existing legacy model | 60 | Legacy V1 engine |
| premium | existing legacy model | 100 | Legacy V1 engine |

The unified engine must never convert one response model into another.

## 3. Runtime flow

```text
Assessment Runtime
      ↓
Unified Assessment Adapter
      ↓
Validate type / count / scoring version
      ↓
Assessment-specific Scoring Engine
      ↓
Assessment-specific Result Contract
```

## 4. Non-negotiable rules

1. No universal score.
2. No raw-average synthesis across unrelated assessments.
3. No global positional mapping for DISC.
4. No Likert normalization for Cognitive objective items.
5. No objective correct-answer semantics for RIASEC preference items.
6. No mutation of historical QuestionVersion records.
7. Scoring semantics remain versioned.
8. The unified layer cannot override an assessment-specific scoring engine.
9. No database migration is required for V8.7.
10. Customer interpretation remains outside this orchestration layer.

## 5. Compatibility

Existing `getScoringEngine()` remains the source of truth for scoring implementations. V8.7 wraps that registry rather than replacing it.

Historical V1 scoring engines remain available for `free` and `premium`, while V2 assessment engines remain isolated by assessment type.

## 6. Acceptance criteria

V8.7 is complete when:

- the unified adapter registry exists;
- all assessment types have an explicit adapter;
- adapter metadata declares the assessment-specific response model and item count;
- scoring-version mismatch fails closed;
- runtime assessment submission uses the unified orchestration entry point;
- assessment-specific scoring implementations remain unchanged in semantics;
- no V8.7 database migration exists;
- V8.7 gate passes after typecheck/build and V8.0–V8.6 gates.
